## What I do

- **AI integration and strategy** — find the high-leverage workflows, then design and ship AI-assisted solutions around them.
- **Automation** — connect the tools teams already use (Notion, ManyChat, Shopify) so work flows without manual copy-paste.
- **Product building** — full-stack web apps with Next.js, TypeScript, and the Vercel AI SDK.

## Featured work

### [yap-app](https://github.com/webdevkobi/yap-app) — AI speaking coach
A web-first, 60-second daily speaking coach. It records a short rep and returns a Yap Score plus AI coaching through the Vercel AI Gateway, with a local-first scoring fallback so it runs with no API keys.

`Next.js` · `TypeScript` · `Vercel AI SDK` · `Zod`

### ManyChat → Notion automation
A pipeline that connects ManyChat conversations to a Notion workspace, so audience interactions are captured and organized automatically instead of by hand. Deployed on Vercel.

`ManyChat` · `Notion API` · `Vercel`

### Champion's Voice storefront
Shopify theme and storefront work (Liquid) for Champion's Voice, a coaching and development program for student-athletes.

`Shopify` · `Liquid`
